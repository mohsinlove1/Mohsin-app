MOHSIN APP - GitHub Actions APK Build

1. Create a GitHub repository and upload all files in this project.
2. Use the default branch named main (master also works).
3. Open the repository's Actions tab.
4. Select "Build MohsinApp APK".
5. Click "Run workflow".
6. When the job finishes, open the workflow run.
7. Under Artifacts, download "MohsinApp-debug-apk".
8. Extract the downloaded ZIP and install the APK on your Android phone.

No Android Studio is required for the GitHub build.
